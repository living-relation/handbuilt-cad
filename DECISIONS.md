- 2026-11-04: CNC machined parts follow `docs/CNC-MACHINING-RULES.md`, from Xometry "Design Guide: CNC Machining" (38 pp, PDF 16 Apr 2025). For CNC parts the guide's walls are the rule: 0.030" (0.762 mm) metal, 0.060" (1.52 mm) plastic/composite. The structural-only / never-assumed minimum wall is for 3D printed parts only. Project rules in AGENTS.md / DECISIONS.md still win where they are stricter. (The 2026-11-04 "1.3× is documented only" clause was superseded on 2026-11-14.) (maintainer)
- 2026-11-14: CNC rules for agents: inside corners at 1.3× the nearest standard tool radius, never an exact standard tool size (`cnc_check.py` flags both). A CNC wall under 0.030"/0.060" fails; printed parts keep the structural-only rule. Edge breaks are never auto-applied: modeled chamfers/fillets are dimensioned with no general note; unmodeled cut-risk edges get a user prompt and, only if approved, a leader `BREAK ALL EDGES, STD` or a given length; prefer 45° chamfers. Tapped holes 1.5× screw diameter, matching holes the same depth, flag over 2×D. Inserts stay in the assembly model; the shop STEP omits them. Title-block tolerances stay the project default; the Xometry table is the shop default if silent (not ISO 2768); tighter than ±0.005" is a cost flag. The source PDF lives in the models folder `references/`, not in this repo (1 MB limit). (maintainer)
- 2026-11-15: 1.5×D is the **minimum** thread engagement (flag if under). Over 2×D remains a flag. Neither limit may change drawing text. Blind tapped holes are always called out at the actual thread depth; when the hole is deeper than the thread, both depths are called out. Through holes (plain and tapped) are `THRU` with no depth. If thread depth is unknown, flag it; do not invent a number. The in-repo source for the Xometry guide is `docs/references/xometry-design-guide-cnc-machining-2025-04-16.md`; the PDF stays in the models folder. (maintainer)

- 2026-11-15: Over 2×D thread depth is **never a flag** (supersedes the "Over 2×D remains a flag" clause above). The guide's ≤ 2×D shop note may be quoted with its page cite. Only under-1.5×D engagement is flagged, and it must not change drawing text. (maintainer)
