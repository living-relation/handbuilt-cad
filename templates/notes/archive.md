# _archive (parts home)

Owner: handbuilt-cad (https://github.com/living-relation/handbuilt-cad). Note written by `tools/folder_notes.py` (setup and publish-to-models), add-only.

Used by: the parts home (`tools/paths.py`) and publish-to-models, which file history here.
Deleting, moving or renaming this folder loses the only copy of old versions and backups.

- `<job>/`: iteration history, superseded script versions and other items kept only for reference. Nothing here is used by a build.
- Backups or history bundles taken before a cleanup or move may also live here, each with a note or hash list saying what it holds.
- Nothing here is deleted without the owner's yes. Paired folder: the parts home one level up (`../`).
