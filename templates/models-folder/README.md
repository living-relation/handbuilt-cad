# models (owned by handbuilt-cad)

Finished CAD parts from the **handbuilt-cad** repo (https://github.com/living-relation/handbuilt-cad).
Used by handbuilt-cad's `publish-to-models` skill and tools. Deleting or moving this folder breaks them.
Layout: `<job>_<MMDD>/<rev>/`. Never move, rename or edit existing revs; old versions may be deleted under the retention rule (latest + 2 previous per assembly, parts they use, max 2 screenshots per model, never 3D scans). See `AGENTS.md` for the rules.
