# models (owned by handbuilt-cad)

Finished CAD parts from the **handbuilt-cad** repo (https://github.com/living-relation/handbuilt-cad).
Used by handbuilt-cad's `publish-to-models` skill and tools. Deleting or moving this folder breaks them.
Layout: `<job>/rev<LETTER>/` (existing job names kept): assembly AP242 STEP at the version root, `Parts/` beside it, `drawings/`, `SUMMARY.md`. No .f3d, scripts, runs, or scans. Keep the 2 latest versions of each assembly; never delete 3D scans. See `AGENTS.md`.

CNC-machined parts: follow handbuilt-cad `docs/CNC-MACHINING-RULES.md`, the in-repo text conversion `docs/references/xometry-design-guide-cnc-machining-2025-04-16.md`, and the Xometry PDF in `references/xometry-design-guide-cnc-machining-2025-04-16.pdf`.
