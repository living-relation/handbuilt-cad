# Fairsolid: where it lives

**`pipelines/fairsolid/` in this repo is Fairsolid.** On 2026-10-17 the owner chose this copy as the one real Fairsolid. The old `living-relation/fairsolid` GitHub repo (and `living-relation/fairsolid-archive`) was deleted from GitHub by the owner on 2026-10-21; it is not archived. Its local checkouts were moved to the archive folders below. Make every Fairsolid change here, through a normal handbuilt-cad PR.

## Using it
- Build its venv (separate from the CAD `.venv`, because the two OCP builds conflict): `bash setup.sh --with-fairsolid` (runs `uv sync --frozen --extra test` in `pipelines/fairsolid/`).
- Run it with `pipelines/fairsolid/.venv/bin/fairsolid ...`, or through `tools/scan_helper.py`. That helper uses `FAIRSOLID_HOME` if it is set, and otherwise this repo's `pipelines/fairsolid/`.
- Tests: `cd pipelines/fairsolid && .venv/bin/python -m pytest -q` (leave `PYTHONIOENCODING` unset). Test meshes are generated by `tests/make_fixture.py`: a synthetic plate with a boss and bore, not a part model. They are gitignored (`scan.stl` is about 158 MB).
- New run folders go outside git. Use `[paths] fairsolid_runs` in `local.toml` (`FAIRSOLID_RUNS`), or the gitignored `pipelines/fairsolid/runs/`.
- Grok Bot handoff kit: `pipelines/fairsolid/scripts/make_handoff.py` with its templates in `scripts/handoff_templates/`. The zip goes to the gitignored `pipelines/fairsolid/handoff/`, and the job's run comes from `--runs` (default `FAIRSOLID_RUNS`, then `runs/`).
